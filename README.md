# College-Student-Placement-Analysis-using-MYSQL-
1️⃣ Project Title / Headline

College Student Placement Analysis using SQL

 2️⃣ Short Description / Purpose

This project analyzes college student placement data using SQL to identify key factors influencing employability.

The objective is to study the relationship between academic performance, internship experience, skills, IQ levels, and placement outcomes.

Using MySQL, the project demonstrates how structured queries can generate actionable insights for improving student placement success rates.

 3️⃣ Tech Stack

MySQL (Relational Database Management System)

SQL (Structured Query Language)

ER Modeling

Aggregate Functions (AVG, COUNT, MAX)

JOIN Operations

Constraints (Primary Key, Foreign Key)

 4️⃣ Data Source

The dataset was manually created and structured into relational tables:

Students

AcademicPerformance

Experience

Skills

Placement

The data includes:

CGPA

IQ

Internship Experience

Projects Completed

Communication Skills

Academic Performance Score

Placement Status

 5️⃣ Features & Highlights
 Business Problem

Colleges need to understand:

What factors influence student placement?

Does CGPA significantly impact placement?

Do internships and projects increase employability?

How do communication skills affect placement success?

This SQL project answers these questions using relational database analysis.
